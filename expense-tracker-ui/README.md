# Expense Tracker UI

Client application built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Tech Stack
- **Framework**: React 18 + Vite 5
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Port**: `5173`

## Running Locally
```bash
npm install
npm run dev
```

The dev server proxies `/api/*` requests to `http://localhost:8084` to prevent CORS issues in development.

## Production Build
```bash
npm run build
npm run preview
```
